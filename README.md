# Portfólio — João Pedro Penna

Site estático em HTML, CSS e JavaScript puros.

## Estrutura

```
portfolio/
├── index.html
├── css/style.css
├── js/script.js
├── img/perfil.jpeg   <- coloque sua foto aqui
└── README.md
```

## Como rodar

1. Abra a pasta `portfolio` no VS Code.
2. Clique em **Go Live** (extensão Live Server).

## Como publicar no GitHub Pages

Substitua os arquivos do repositório `portfolio` pelos desta pasta, faça commit e push.
A foto precisa estar em `img/perfil.jpeg` (ou ajuste o caminho no `index.html`).
